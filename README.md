## 游戏云有两副面孔，买错多半错在这

雨云游戏云分成 VPS 版和面板版，两者不是同一套东西，下单前必须分清。

**VPS 游戏云**给你完整系统权限，Linux 或 Windows 自选，SSH、RDP、VNC 都能连。能挂 Robot 框架，能开群组服，支持 MCDR，一台机器上想跑几个服务端跑几个。代价是需要一点开服经验，至少得知道怎么装 Java、怎么写启动脚本。配置从 2 核 4G 10M 起步，最高到 8 核 32G 30M。

**面板游戏云**基于 MCSM 面板，全程网页点点点，不用碰命令行。带宽固定 50Mbps 上行，IP 是 NAT 映射，最低 1 核 2G 就能开。它不能开群组服，也不能挂 Robot 框架，扩展性明显低一档。零基础或者只开一个标准服，选它省事；想折腾模组、多服联动，面板版会让你很快撞墙。

端口数量在测评资料里有两个说法，一处写 15 个端口转发，一处写面板服给 10 个端口。两者可能对应不同产品线，下单前在配置页自己确认一遍，别按记忆里的数字规划。

## 为什么开服要挑高主频 CPU

Minecraft Java 版的主线程基本跑在单核上，你给它 32 核，它照样主要吃一个核。主频越高，TPS 越稳，十几个人同时在线、红石和生电机器一起转的时候差别就出来了。

雨云游戏云的主力型号里，i9-14900K 最高 6.3GHz，AMD Ryzen 9 9950X 最高 5.8GHz，Ryzen 9 5900X 最高 4.8GHz，往下还有 Gold 6146、E5-2666 v3 这类主频低一些但核心多的型号。论坛用户实测 i9-14900K 跑 Geekbench 6，单核 2830、多核 8133，UnixBench 单核 3309，单核成绩在同价位国产云里属于靠前的那批。有测评作者在温州机房用 4 核 8G 的 14900K 跑 Purpur 1.21 加十几个插件，七八人在线 TPS 稳在 20。

选型上，E5-2666 v3 这类低频多核适合预算紧、人数少的小服；生电和模组服优先 5900X 以上的高主频型号，核数不用堆太多，4～6 核足够。

## 动态计费和固定计费，哪个更省

固定计费是月租写死，CPU 跑满还是空转都一个价，账目清晰，不用担心半夜被扣钱。24 小时有人在线、随时可能上人的中大型服，选它。

动态计费的基础租金低，CPU 使用率超过 20% 的那部分按“CPU 电量”日结额外收费。1 CPU 电量约等于 30% CPU 占用跑 1 分钟，单价大致在 0.0005～0.001 元，系统每天还会送一定量的免费电量。

判断规则很简单：白天基本没人、晚上开几个小时的服，动态计费更省，闲时几乎不产生额外费用；24 小时高负载的服，动态计费反而会超过固定月租。有测评作者用动态计费跑工作日白天无人的小服，一个月 CPU 电量费只有几块钱，总支出比固定计费省了将近一半；也有开服教程的作者直接建议选固定计费，“全程火力全开”不用算账。两种说法都对，前提不同而已。

## NAT 还是独立 IP：一个 150 元的差价，一条官方警告

NAT 机是共享公网 IP，只给你分配端口，价格便宜，纯开游戏服完全够用。MC Java 版默认端口 25565，基岩版 19132，映射一条规则就能连。独立公网 IP 要另外加钱，资料里的报价是 150 元/月/个，适合同时跑游戏服和 Web 服务、或者需要大量端口映射的场景。

端口映射在实例详情页的网络设置里配，填三项：外部端口（一般随机生成）、内部端口（服务实际监听的端口）、协议。MC Java 版用 TCP，基岩版用 UDP，Steam 游戏用 UDP，Windows 远程桌面用 TCP 或 TCP+UDP，远程桌面默认 3389。

官方教程里有一条警告重复了三遍：**NAT 机不要用来建站，国内禁 TCP 建站。** 你要是打算一台机器既开服又挂网站，直接上独立 IP，别在 NAT 上试。

## 开服前要先搞定的三件事

1. **Java 版本别装错**：MC 1.8～1.12 用 Java 8，1.12～1.16 用 Java 11，1.16～1.20 用 Java 17 或 21，1.21 用 Java 21。版本对不上，服务端直接起不来。
2. **端口映射先配再进游戏**：NAT 机没映射端口，游戏里连不上是必然的。检查内部端口是否和服务端实际监听的一致，外部端口有没有被占用。
3. **配置按人数对号入座**：3～5 人简单生存，E5-2666 v3 3 核 6G 够用；10～20 人中等生电，5900X 或 7950X 的 2～4 核、12～16G；超大生电上 9950X 或 i9-14900K，2～6 核、24～32G。生电服硬盘 50G 一般就够。

幻兽帕鲁的话，官方推荐 4 核 16G，最低 8G，最好 32G 以上；雨云自己的教程建议 4 核 8G 起，机型选 5900X、Gold 6146 或 14900KF。配置文件在 `pal/Pal/Saved/Config/LinuxServer/PalWorldSettings.ini`，要先把 `DefaultPalWorldSettings.ini` 的内容复制进去再改，改完重启实例生效。
